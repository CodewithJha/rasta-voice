Self-hosted OFL fonts for the desk and chit (issue 30).

Sources, copied as woff2 Latin subsets with `font-display: swap`. No CDN.

- Atkinson Hyperlegible 400 and 700 from @fontsource/atkinson-hyperlegible 5.3.0 (Braille Institute, SIL Open Font License 1.1). See OFL-Atkinson-Hyperlegible.txt.
- Fraunces variable (weight axis) from @fontsource-variable/fraunces 5.3.0 (Underscore Type / Google Fonts, SIL Open Font License 1.1). See OFL-Fraunces.txt. Weight 560 and 700 resolve on this file.
- Martian Mono 400 and 600 from @fontsource/martian-mono 5.3.0 (Evil Martians, SIL Open Font License 1.1). See OFL-Martian-Mono.txt.
